# ARIVINE — Embrace with Elegance

An ultra-luxury fashion website designed as a private couture house experience.

## 🎯 Philosophy

This website embodies restraint, silence, and confidence. It doesn't announce itself—it whispers. Every element reinforces that luxury is about what you choose not to show.

## ✨ Features

- **Cinematic Entry**: 2-second logo reveal with warm golden light
- **Editorial Photography**: High-end fashion imagery with natural lighting
- **Smooth Performance**: 60fps animations, no layout shifts
- **Original Design**: Custom visual language—no familiar templates
- **Mobile Optimized**: Luxury experience on all devices

## 🎨 Design System

**Colors:**
- Deep Black: `#0A0A0A`
- Ivory: `#F8F6F1`
- Muted Gold: `#C9A961`

**Typography:**
- Cormorant Garamond (Editorial)
- Inter (Body)

**Motion:**
- Slow, weighted transitions (0.6s - 1.2s)
- Cubic-bezier easing for elegance
- No bounce or elastic effects
